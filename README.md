# Internet Speed Checker

Небольшой консольный скрипт для оценки скорости скачивания по указанному HTTP(S)-адресу.

Скрипт **10 раз последовательно** выполняет GET-запрос к одному URL. Следующий запрос начинается только после того, как тело предыдущего ответа полностью прочитано. Для каждого запроса выводятся HTTP-статус, объём данных и время загрузки.

## Требования

- Python 3.10 или новее
- Сторонние библиотеки не нужны — используется стандартная библиотека Python.

## Запуск

```bash
python speed_test.py https://example.com/image.jpg
```

При необходимости можно изменить таймаут одного запроса (по умолчанию 30 секунд):

```bash
python speed_test.py https://example.com/image.jpg --timeout 60
```

В качестве адреса лучше использовать прямую ссылку на достаточно большой файл, например изображение или архив. Сервер должен разрешать повторные GET-запросы.

## Что выводится

- Время каждого из 10 запросов.
- Среднее время одного запроса.
- Суммарный объём скачанных данных.
- Общее время загрузки.
- Итоговая скорость скачивания.
